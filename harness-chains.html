Build-order step 6: the queue of §8.1, the disciplinary tagging of §8.2 and the amber rule, plus §4.3’s disciplinary lens on the D key.

The queue does not push the model. Every mechanism is already in §7, so an entry that carried a magnitude of its own would double-count one of them. Each lever change instead carries a shadow run — the same run with that one change removed — and an entry’s magnitude is the movement of the difference between the two in the quarter it fires. The lag windows in PARAMS.chains say when a mechanism is still moving its target; the model says by how much.
